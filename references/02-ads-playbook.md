# 广告方案与广告组配置

> **分两类内容，不要混着用：**
> - **【通行做法】** = 亚马逊广告后台的客观结构或行业普遍约定。
> - **【经验区间】** = 推导方法与常见参考值，不是平台规则，必须用你自己的账户数据校准。
>
> 团队已有自己的广告命名规范时，**以团队规范为准并整体替换 §2**。

---

## 1. 结构原则【通行做法】

- 广告后台的层级是 **Portfolio（广告组合）→ Campaign（广告活动）→ Ad group（广告组）→ 关键词 / 商品定向**
- **一个广告活动只放一种投放逻辑**：精准词、词组词、自动投放、商品定向各自独立。混在一起预算会被单价最低的那个吃光，且无法归因
- 一个广告组内的关键词**越少越好管**，建议 5-10 个；同类词（同一词根、同一意图）放一组
- 一个产品线建议对应一个 Portfolio，便于整体看花费与 ACOS

## 2. 命名规则（默认模板，可整体替换）

团队没有现成规范时，用这套：

```
{店铺代号}-{ASIN或子ASIN}-{投放形式}-{匹配/定向}-{序号}
```

- 投放形式：`SP`（商品推广）`SB`（品牌推广）`SBV`（品牌视频）`SD`（展示型推广）
- 匹配/定向：`AT`（自动）`EX`（精准）`PH`（词组）`BR`（广泛）`ASIN`（商品定向）`CAT`（类目定向）
- 广告组名 = 广告活动名 + `-【自定义分类】`（如 `-【大词】`、`-【竞品】`、`-【防御】`）
- 全英文、无空格、无中文，序号两位补零便于排序

示例：

```
MYSHOP-B0XXXXXXXX-SP-AT-01
MYSHOP-B0XXXXXXXX-SP-EX-01-【大词】
MYSHOP-B0XXXXXXXX-SP-ASIN-01-【竞品】
```

> 同一 Campaign 下所有广告组共用同一前缀，只靠最后的【】区分；换人接手时一眼能看出投放意图。

## 3. 关键词分层与数量【经验区间】

| 层 | 数量建议 | 匹配 | 作用 |
|---|---|---|---|
| 核心词 | 3-8 个 | Exact | 主攻转化，控 ACOS |
| 长尾词 | 10-50 个 | Phrase / Broad | 拓词与捡漏 |
| 竞品词 / ASIN | 3-10 个 | 商品定向 / 类目 | 截流 |
| 否定词 | 持续追加 | Negative Exact / Phrase | 防漏 |

**分组粒度**：如果拿得到后台品牌分析的 ABA 排名，按排名分档建组更精细（大词一组、中词一组、长尾一组）；拿不到排名时**按搜索量粗分**，并在交付物里标注「分档未校准」，不要假装有排名数据。

> 千万不要把「月搜索量」当成「ABA 排名」用——两者不同口径，一个词的搜索量高不代表排名好。

## 4. 预算推导【经验区间】

```
目标日单量 × 广告单占比 = 广告单数
广告单数 ÷ 预估 CVR = 需要点击数
需要点击数 × 预估 CPC = 日广告花费
```

例：目标 5 单/天 × 广告占 60% = 3 单 ÷ CVR 8% = 37.5 次点击 × CPC £0.48 ≈ £18/天。

**预算下限**：单活动日预算应至少能跑出「CPC × 10 次点击」，否则一周攒不出判断依据。低于这个数的活动，合并掉。

## 5. 竞价策略【通行做法 + 经验】

| 后台选项 | 适用 |
|---|---|
| 动态竞价-只降低 | 稳定期控 ACOS，防守型 |
| 动态竞价-提高和降低 | 需要抢首页位置时（新品期、大促） |
| 固定竞价 | 需要成本可预测、配合位置溢价手动调 |

位置溢价（Bid adjustments）：首页首位 / 商品页面 / 搜索其余位置。给建议时必须写清「哪个位置 + 加多少」，不写「建议提高出价」。

**出价上限倒推**：

```
可接受 CPC = 售价 × 毛利率 × 目标广告费占比 × 预估 CVR
```

算出来低于类目底价，说明这个价位打不动——要么提价，要么换词，不要硬顶。

## 6. 分阶段节奏【经验区间】

| 阶段 | 时间锚点 | 主目标 | 要点 |
|---|---|---|---|
| 启动期 | 上架 0-14 天 | 拿到初始转化与评价 | 精准 + 自动并行，高 ACOS 此时不否决；评价 <5 条前不开大词广泛 |
| 成长期 | 15-60 天 | 拓词 + 稳排名 | 加词组/广泛，按搜索词报告扩否词 |
| 成熟期 | 60 天后 | 压 ACOS、提利润 | 收缩低效词，预算挪到高转化词与防守词 |

**老链接重启**（已上架很久但转化差）：不要直接按新品节奏加预算，先修页面（主图、参数、评论），广告只开保命预算，等 CVR 有改善再加。

## 7. ACOS / ROAS 目标【经验区间】

```
盈亏平衡 ACOS = 毛利率（不含广告）
目标 ACOS = 盈亏平衡 ACOS × 目标广告利润留存比例
ROAS = 1 ÷ ACOS
```

启动期允许 ACOS 高于盈亏线，但必须写明「允许期多长、到期未达标怎么处理」。成熟期 ACOS 必须低于盈亏线，否则投得越多亏得越多。

## 8. 广告类型与上线门槛【通行做法】

- 新链接评价数太少时，SB / SBV 落地页转化接不住，钱容易浪费——**先在 SP 上跑出评论与 CVR 再上品牌广告**
- 品牌广告需要品牌注册；品牌旗舰店（Store）缺失时，SB 的落地页质量差，建议暂缓
- 商品定向（ASIN）单独建活动，否则它的高 ACOS 会被主推活动的预算掩盖
- 品牌词与竞品词分开核算，不要合并汇报 ACOS

## 9. 监控节奏【经验区间】

| 频率 | 看什么 | 触发动作 |
|---|---|---|
| 每日 | 花费、点击、预算是否烧穿 | 烧穿过快 → 查高花费词；0 曝光 → 查出价与词相关度 |
| 每周 | 搜索词报告、否词清单 | 点击 ≥10 且 0 单 → 否词；ACOS 超目标 2 倍 → 降价或降预算 |
| 每两周 | 活动结构是否该拆/合、竞价策略是否该换 | 广泛活动吃掉主推预算 → 拆活动 |
| 每月 | 广告占比、自然单占比、整体利润率 | 广告占比过高 → 收广告、提自然权重 |

## 10. Listing 与广告协同【通行做法】

广告只放大页面已有的转化能力，**页面没改好就加预算 = 加速烧钱**。

- 主推核心词是否出现在 Title / Item Highlights（不出现 = 花钱买不匹配流量）
- 五点顺序是否与活动主次一致（主推卖点应在前两条）
- 主图与 A+ 是否承接了广告词的承诺
- 价格与优惠是否匹配投放力度
- 广告带来的搜索词是否回流到关键词表（闭环，别单向看）

## 11. 广告组配置字段（逐组必填）

| 字段 | 取值要求 |
|---|---|
| Portfolio | 产品线或店铺维度组合 |
| Campaign name | §2 规则 |
| Ad group name | 活动名 +【自定义分类】 |
| 每日预算 | 金额 + 币种 + 推导算式 |
| 广告活动类型 | SP 自动 / SP 手动 / SB / SBV / SD |
| 广告投放定位 | 自动 / 手动 |
| 竞价策略 | 三种之一 |
| 投放关键词 | 按 §3 数量建议 |
| Match type | Exact / Phrase / Broad / ASIN 定向 / 类目定向 |
| TARGETING GROUPS | 关键词组 / ASIN 列表 / 类目；自动活动写投放组 |
| Negative keyword / Negative product | 组级否定清单 |
| Bid adjustments | 位置 + 百分比 |
| 备注 | 分档依据、待确认项 |

信息缺失写 `待补充`，并在末尾单列「待确认清单」。不留空、不填 0 冒充已知。

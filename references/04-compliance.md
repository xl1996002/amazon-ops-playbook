# 合规与用词红线

> 这份清单是「宁可不用」的清单。拿不准的词换成可验证的事实描述。

## 1. 禁用表达（一律不出现）

绝对化 / 无法证明：

```
Best · No.1 · #1 · Number One · Top Rated · Bestseller · Perfect · Guaranteed
100% Safe · Never · Most Advanced · Ultimate · Unbeatable · Cheapest · Free
```

其他禁止：

- 品牌名（自有与他方皆禁）、商标、ASIN、竞品品牌
- 未经授权的兼容性表达（"Compatible with [品牌]" 需授权）
- 价格、折扣、配送、赠品、限时促销信息（属于促销字段，不写进 Listing 文案）
- 医疗、疗效、治疗类断言
- 虚假认证、无依据的环保/无毒/食品级声称
- 竞品贬低、对比指名道姓

## 2. 需取证词（产品资料明确支持才能用）

| 词 | 需要的证据 |
|---|---|
| Waterproof / Water-Resistant | 防水等级测试或明确标注 IP 等级 |
| Heavy Duty | 承重测试数据 |
| Medical Grade / Non-Toxic / BPA Free | 材料检测报告 |
| Food Safe / Food Grade | 食品接触材料合规证明 |
| Eco-Friendly / Recyclable / Biodegradable | 材料或认证依据 |
| Antibacterial / Sterilizing | 检测报告，且不得延伸到医疗功效 |
| Hypoallergenic | 过敏测试或材料依据 |
| Fireproof / Flame Retardant | 阻燃等级证明 |

资料里没有证据就用可观察的事实替代：

```
不要写：Waterproof shelf for bathroom
改 写：Sealed surface wipes dry after splashes, keeping the shelf tidy in steamy bathrooms
```

## 3. Title Case 规则

标题与 Item Highlights 使用 Title Case，以下单词通常小写：

```
a · an · the · and · or · but · for · of · in · on · at · to · with · from · by
```

- 位于开头时首字母大写
- 冒号、破折号后的第一个词首字母大写
- 全大写缩写保持原样（如 USB、LED、XL）
- 数字与单位按品类习惯（4 Piece、2 Pack）

## 4. 类目风险点

| 类目 | 高频踩坑 |
|---|---|
| 家居 / 收纳 | 承重未标、尺寸与图示不符、"space saving" 无场景支撑 |
| 电子 | 兼容性表达无授权、认证未标、"universal" 实为不兼容 |
| 母婴 / 儿童 | 年龄段声称、安全认证缺失 |
| 美妆 / 个护 | 功效断言、医疗化表述 |
| 食品接触 | Food Safe 无检测报告 |
| 服装 | 尺码偏差、面料成分不实 |

## 5. 变体与子 ASIN

- 标题通常不含颜色/尺寸（由变体主题承载），避免多子 ASIN 标题重复冲突
- 各子 ASIN 的五点与描述需与自身变体属性一致，不能共用一段写着"含 4 件"的文案却卖 2 件装
- 同一父体下不同颜色/尺寸的价格差异不要写进文案

## 6. 交付前的合规三问

1. 这个句子里的每个数字，能不能指到具体资料页？
2. 这个形容词，客户投诉时我拿什么证明？
3. 这个表达，竞品投诉我侵权时我站得住吗？

三问有一个答不上来，改成事实描述。

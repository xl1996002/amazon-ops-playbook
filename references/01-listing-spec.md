# Listing 文案规范

> 本文件是页面文案的唯一规则来源。逐条执行，不要凭经验改写；与用户临时要求冲突时以用户为准，但要指出冲突点。

## 0. 输入参数

动笔前确认：

- 目标站点：英国站 / 德国站 / 法国站 / 美国站 …
- 输出语言：英语 / 德语 / 法语 …
- 产品资料：尺寸、材质、数量、颜色、配件、承重等信息
- 产品图片：全部图片逐张看完，不要只看主图

## 1. 产品分析与市场定位

从图片和资料里识别：产品类型、结构、材质、颜色、包装数量；主要功能与核心卖点；目标买家及购买动机；目标国家买家的主要使用场景；产品能解决的实际问题；买家下单前最关注的问题和顾虑；相比普通同类产品的购买价值点。

结合目标国家的生活方式、住宅环境、气候、空间大小、使用习惯，选**最有转化价值**的场景，而不是泛泛的"多种场景"。

### 卖点撰写逻辑（固定四段式）

```
买家需求或痛点 → 产品功能或结构 → 给买家带来的实际好处 → 对应使用场景
```

不要只罗列参数。每个卖点都要说明「这个特点解决什么问题、带来什么实际价值」。

**禁止编造**：尺寸、材质、数量、颜色、承重、防水等级、认证、兼容范围、包装配件、产品性能。关键信息无法确认时，先列出要确认的问题，不要擅自补充。

## 2. 关键词策略（必须在写文案前完成）

关键词表是后续所有模块的输入。先建表、再分配、再动笔。

### 2.1 建立关键词表（七分类）

| 分类 | 定义 |
|---|---|
| 核心词 Core | 产品最主流的通用名称，搜索量最大，必须覆盖 |
| 长尾词 Long-tail | 3 个词以上的精准搜索短语，转化意图更强 |
| 属性词 Attribute | 材质、尺寸、颜色、规格、数量 |
| 场景词 Scenario | 使用场景、地点、时机 |
| 人群词 Audience | 适用对象或目标人群（避开平台禁用的敏感人群词） |
| 同义词 Synonym | 同一产品的其他常见叫法 |
| 替代方案词 Alternative | 买家搜替代品的词（不得用竞品品牌名） |

要求：

- 所有关键词来自目标国家买家的真实搜索表达，**不得凭空编造或直译中文**
- 不含品牌名、商标、ASIN、竞品品牌、未经授权的兼容性表达
- 不含平台禁用的绝对化、无法证明或敏感词
- 与产品资料一致，不为凑词加入产品不具备的属性

输出格式：

```
核心词：[词1] | [词2] | [词3]
长尾词：[词1] | [词2] | [词3]
属性词：[词1] | [词2] | [词3]
场景词：[词1] | [词2] | [词3]
人群词：[词1] | [词2]
同义词：[词1] | [词2]
替代方案词：[词1] | [词2]
```

### 2.2 关键词分配（一个词只主攻一个位置）

标题只有 75 字符，词位极度紧张。必须把词分配到不同模块，而不是每个模块都塞一遍。

| 位置 | 分配原则 | 词数建议 |
|---|---|---|
| Title | 只放优先级最高的核心词 + 1-2 个关键属性词 | 2-4 个 |
| Item Highlights | 标题未覆盖的次要核心词、材质词、场景词 | 3-5 个 |
| 五点描述 | 每条 1-2 个，以长尾词和场景词为主 | 5-10 个 |
| 产品描述 | 长尾词、场景词、人群词自然融入句子 | 6-10 个 |
| Search Terms | 剩余未覆盖的同义词、替代方案词、拼写变体 | 250 字节内 |

硬性要求：

- 同一关键词不得在 Title 与 Item Highlights 中重复出现
- 同一关键词不得在 5 条卖点中被重复主攻
- 同一关键词不得同时出现在 Item Highlights 与 Search Terms（前者前台可见，后者只放未覆盖词）
- 核心词 100% 覆盖，长尾词至少覆盖 80%
- 核心词因字符限制进不了标题时，必须在 Item Highlights 或五点补上

### 2.3 自然埋词的三条判断标准（必须同时满足）

1. 去掉关键词后，句子依然通顺完整
2. 句子的主语是买家或买家的使用场景，而不是关键词本身
3. 读起来像正常的当地语言，不像翻译腔，也不像词表

反例（机械堆砌，禁止）：

```
Durable, sturdy, strong, heavy duty, long lasting, premium quality stainless steel measuring cups
```

问题：形容词串联，没有句子结构，买家读不到利益点。

正例：

```
Clear metric and US markings let you follow any recipe without conversion errors.
```

另一组对比：

- 反例：`Waterproof, anti-slip, easy clean, space saving bathroom shelf`
- 正例：`Rounded edges and a non-slip base keep the shelf steady, even on wet bathroom tiles.`

## 3. 文案总体要求

- 符合亚马逊规则，不侵权，不使用竞品品牌、商标、ASIN 或未经授权的兼容性表达
- 不使用 `Best` `No.1` `Perfect` `Guaranteed` `100% Safe` `Never` `Most Advanced` 等绝对化或无法证明的表达
- `Waterproof` `Heavy Duty` `Medical Grade` `Non-Toxic` `Food Safe` `Eco-Friendly` 等需证明的词，只有在产品资料明确支持时才能用
- 关键词必须丰富、准确、自然融入，不能机械堆砌
- 优先用目标国家买家常用的本土化搜索词和表达，避免生硬翻译
- 每条只表达一个主要购买理由，模块之间避免重复
- 重点展示买家关注点、实际需求和使用结果，不要只介绍产品本身
- 标题与 Item Highlights 用 Title Case，以下介词/冠词/连词通常小写：
  `a, an, the, and, or, but, for, of, in, on, at, to, with, from, by`
  这些词位于开头时首字母大写

## 4. 输出模块

### 4.1 产品定位分析（中文）

输出：产品类型、目标买家、目标国家主要使用场景、买家核心需求、买家主要痛点、下单前主要顾虑、产品核心优势、建议主推关键词、建议避免的风险词。

简洁，不要写成长篇市场报告。

### 4.2 Title

- **最多 75 个英文字符**（含空格和标点）。上限按类目与站点政策会变，本篇以 75 字符为例，上线前请核对当前后台限制
- 不为凑满 75 字符加无效词
- 优先保留核心产品名称、重要规格、主要功能、关键使用场景
- 只使用分配给 Title 的核心词和属性词
- 不用品牌名、促销词、特殊符号或重复关键词
- 用目标国家买家自然、常用的搜索表达
- 兼顾关键词覆盖、可读性和移动端展示
- 存在变体（颜色/尺寸）时，标题通常不含变体属性，由子 ASIN 变体主题承载
- **输出后标注实际字符数**

```
Title: [内容]
Character Count: [字符数]
```

> 字符数按 Unicode 字符计数（不是字节）。中文环境下尤其注意不要用字节数冒充字符数。

### 4.3 Item Highlights

标题的信息补充字段，前台展示于标题下方，搜索结果页和详情页均可见，**内容可被搜索**。

- **最多 125 个英文字符**（含空格和标点）
- 补充标题未覆盖的材质、使用场景、适用对象、次要用途
- 只用分配给 Item Highlights 的词，不重复标题已充分表达的关键词和卖点
- 输出 4-6 个简短关键词组或短语，逗号分隔，Title Case，介词小写
- 不写成长句或完整段落
- 不用空泛、主观或无法证明的词
- 与 Search Terms 分工：Highlights 前台可见且可搜索，需要可读性；Search Terms 后台隐藏，纯关键词补充
- **输出后标注实际字符数**

```
Item Highlights: [内容]
Character Count: [字符数]
```

### 4.4 五点描述

5 条，每条：

- 只展示一个核心卖点，不与其他条重复
- 以简短的 Title Case 卖点标题开头
- 建议 1-2 个简短句子
- 先讲买家能获得的实际好处，再讲产品功能或结构依据
- 自然融入 1-2 个分配给五点的长尾词或场景词，须满足 2.3 三条标准
- 5 条之间不得重复主攻同一个关键词
- 必须结合目标国家买家的实际使用场景
- 明确解决买家痛点或下单顾虑
- 不写空泛表达（如"适合多种场景""提升生活品质"）
- 不加图片或资料无法证明的功能
- 不重复标题已充分表达的信息

排序逻辑（可按品类调整）：

1. 解决买家最核心的使用问题
2. 关键功能或结构带来的实际好处
3. 材质、稳定性、耐用性或使用体验
4. 安装、清洁、收纳、携带或操作便利性
5. 目标国家常见使用场景、适用空间或兼容范围

品类微调示例：

- 电子：兼容性/安全认证 → 核心功能 → 材质做工 → 使用便利性 → 适用场景
- 服装：面料/尺码 → 穿着场景 → 工艺细节 → 洗护方式 → 搭配建议
- 家居：解决核心问题 → 功能好处 → 材质耐用性 → 安装便利性 → 适用空间

```
【卖点标题】正文
（×5）
```

### 4.5 产品描述（两个版本，内容一致）

#### 版本一：HTML 描述

- 可直接复制到亚马逊后台的基础 HTML
- 不要用 Markdown 代码框包裹 HTML 内容
- 仅用基础标签：`<p>` `<br>` `<b>` `<ul>` `<li>`
- 不用 CSS、JavaScript、表格、图片、链接、颜色、特殊字体或字号
- 2-3 个简短段落，必要时加简短列表
- 第一段：解决的主要问题、目标买家、核心用途
- 第二段：目标国家真实使用场景 + 核心功能的实际好处
- 第三段：使用便利性、适用空间、包装内容或购买前需知
- HTML 标签不计入字符数；正文建议 600-800 英文字符（按类目后台限制调整）
- 输出内容中不加解释、备注或复制说明

```
HTML Product Description: [内容]
```

#### 版本二：纯文本描述

- 与 HTML 版信息一致，无任何 HTML 标签
- 2-3 段，段间空一行
- 正文建议 600-800 英文字符

```
Plain Text Product Description: [内容]
```

#### 两版共同要求

- 用目标国家自然、本土化语言
- 重点展示买家实际需求和产品带来的使用价值
- 自然融入分配给描述的长尾词、场景词、人群词，满足 2.3 标准
- 不机械重复标题和五点
- 不逐项堆砌参数
- 不编造品牌故事、认证、性能或售后承诺
- 不使用价格、折扣、配送、赠品或限时促销信息
- 不使用绝对化或无法证明的宣传用语
- 若存在尺寸、兼容性或使用限制，客观提醒买家
- 两版的参数、卖点、包装内容、适用场景必须完全一致

### 4.6 Search Terms

- 输出一行后台搜索词
- **最多 250 字节**（UK/US），不含逗号、标点、品牌词、ASIN
- 只放 Title / Item Highlights / 五点 / 描述中尚未覆盖的词
- 同一单词不重复出现
- 补充剩余同义词、替代方案词、拼写变体
- 用目标国家真实常用搜索表达
- 不用无关流量词、竞品品牌、主观促销词
- 不必重复单复数、大小写或常见拼写变化

```
Search Terms: [内容]
```

### 4.7 图片规范建议（中文）

**主图**：

- 纯白背景（RGB 255,255,255）
- 产品填充画面 ≥85%
- 最短边 ≥1000px 以启用缩放
- 长边 ≤10000px
- 不加文字、水印、Logo（品牌名按类目规则）
- 产品完整可见，不被裁切

**副图（最多 6 张）**，按产品特性选择覆盖：

- 使用场景图：目标国家真实使用环境
- 尺寸对比图：与常见物品或手的比例参照
- 细节特写图：材质纹理、工艺细节、接口/连接处
- 功能图解图：核心功能或安装步骤图示
- 包装内容图：买家收到的全部配件与内容物
- 对比/差异化图：与普通产品的差异可视化

```
图片规范建议：
主图：[建议]
副图1：[建议]
...
```

### 4.8 A+ Content 模块建议（中文）

仅当卖家已完成品牌注册时输出；未注册则跳过此模块。

推荐模块：

- 品牌故事卡：简短品牌定位 + 核心差异化
- 对比表：与普通产品的关键参数对比（≤4 行）
- 使用场景大图：目标国家真实场景生活方式展示
- 功能图解：核心功能可视化
- FAQ：买家最常问的 3-5 个问题及回答

要求：参数、卖点、场景与标题/五点/描述完全一致；不编造认证、性能或售后承诺；图片建议与 4.7 衔接，避免重复拍摄。

```
A+ Content 建议：
模块1：[类型] - [内容建议]
...
```

### 4.9 中文翻译

分别翻译：Title、Item Highlights、五点描述、产品描述（翻译纯文本版即可，不重复翻 HTML 版）。

仅用于内部审核，不逐词直译，但必须准确表达原文含义，不得增加原文没有的卖点。

## 6. 输出前自检清单

### 关键词

- [ ] 已按七分类输出关键词表

- [ ] 核心词 100% 覆盖、长尾词 ≥80%
- [ ] 同一关键词未在 Title 与 Item Highlights 重复
- [ ] 同一关键词未在 5 条卖点中重复主攻
- [ ] 同一关键词未同时在 Item Highlights 与 Search Terms
- [ ] 关键词自然融入完整句子（去掉关键词句子仍通顺）
- [ ] 无形容词式关键词堆砌
- [ ] 已输出关键词覆盖核对表

### 格式与字符

- [ ] Title ≤ 75 字符

- [ ] 标题与 Highlights 中介词大小写正确
- [ ] Item Highlights 有效补充标题且无明显重复

### 内容质量

- [ ] 五条卖点各自独立
- [ ] 每条简短并突出买家利益
- [ ] 体现目标国家真实使用场景
- [ ] 回答买家主要关注点与下单疑虑
- [ ] 同时提供 HTML 版与纯文本版描述
- [ ] HTML 版只用基础标签，无 CSS/脚本/图片/外链

### 合规与一致性

- [ ] 未使用图片或资料未提供的参数

- [ ] A+ 建议（如有）与其他模块信息一致

发现问题直接修正后再输出终版，**不要展示错误版本、修改过程或内部推理**。
